# Разработка интеллектуального ассистента для поддержки деятельности HR-бизнес-партнера
Компания хочет автоматизировать обработку типовых обращений сотрудников по HR-вопросам с помощью интеллектуального ассистента, стремясь снизить операционную нагрузку на HR-бизнес-партнеров, сократить время ожидания ответов и повысить доступность HR-информации для сотрудников.

- **Пользователи:** сотрудники компании, HR-бизнес-партнеры, специалисты, ответственные за актуализацию корпоративной базы знаний.

- **Требования:**
  - сотрудники могут задавать вопросы по HR-процессам на естественном языке;
  - ассистент осуществляет поиск информации в корпоративной базе знаний;
  - ассистент формирует ответы на вопросы сотрудников на основе найденной информации;
  - сотрудники могут получать ссылки на источники информации;
  - при невозможности предоставить ответ ассистент передает обращение закрепленному за сотрудником HR-бизнес-партнеру;
  - HR-бизнес-партнеры получают переданные им обращения сотрудников;
  - сотрудники могут просматривать историю взаимодействия с ассистентом;
  - сотрудники могут оценивать полезность полученных ответов;
  - система поддерживает обновление корпоративной базы знаний.

- **Дополнительный контекст:**
  - значительная часть рабочего времени HR-бизнес-партнеров затрачивается на обработку повторяющихся вопросов сотрудников;
  - система должна обеспечивать конфиденциальность информации и защиту персональных данных сотрудников;
  - ассистент не заменяет HR-бизнес-партнера, а освобождает его от выполнения рутинных задач;
  - в перспективе предполагается интеграция с корпоративными каналами коммуникации;
  - система должна предусматривать возможность масштабирования при увеличении количества пользователей.
